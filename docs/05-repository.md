# 공개 저장소 안내

[README](../README.md)

## 구성

```text
ButterPop_Public/
├─ README.md
├─ Scripts/
│  ├─ Core/       # 서비스, 플랫폼 어댑터, 저장과 사운드
│  ├─ GamePlay/   # 소프트바디, 스테이지와 기믹
│  ├─ UI/         # UI 생명주기, 화면과 팝업
│  ├─ Editor/     # 제작 도구와 검증용 코드
│  └─ Util/
├─ docs/         # 구현 설명과 문제 해결 사례
└─ media/        # PDF, 실제 스크린샷·GIF, 썸네일과 영상
```

프로젝트의 `Assets/02. Scripts`에 있는 애플리케이션 C# 소스 146개를 폴더 구조대로 포함했습니다. 공개 사본에서는 LevelPlay 운영 광고 설정 8개, 리더보드 식별자 1개, 앱인토스 광고 그룹·SKU 5개를 예시 값으로 대체하고 SKU 주석의 예시 식별자를 일반 설명으로 바꿨습니다. 게임 로직을 열람할 수 있도록 관련 인터페이스·데이터 모델·에디터 코드도 함께 포함했습니다.

Scene, Prefab, ScriptableObject 원본 데이터, Unity `.meta`, ProjectSettings, 외부 에셋·SDK 원본, 인증 자료와 빌드 결과물은 포함하지 않습니다. 개발 저장소의 Git 이력도 포함하지 않습니다.

## 실행 가능 여부

이 저장소는 **소스 열람용**입니다. Unity가 참조하는 실제 에셋과 프로젝트 설정, 외부 라이브러리가 없어 단독으로 실행하거나 빌드할 수 없습니다. 코드를 별도 프로젝트로 옮겨도 Inspector 연결과 플랫폼 설정을 직접 구성해야 합니다.

`StageMakerWindow` 등 일부 코드는 원래 프로젝트의 에셋 경로를 참조합니다. 해당 경로가 이 저장소에 존재하지 않는 것은 공개 범위를 제한한 결과입니다.

## 의존성

현재 개발 프로젝트의 버전 정보를 기준으로 작성했습니다. 버전 표시는 프로젝트 설정의 기록이며, 공개 패키지를 빌드해 검증한 호환성 목록은 아닙니다.

| 의존성 | 프로젝트 기록 | 용도 |
|---|---|---|
| Unity Editor | 6000.4.5f1 | 게임·에디터 실행 환경 |
| URP | 17.4.0 | 렌더링 |
| Input System | 1.19.0 | 입력 |
| Localization | 1.5.12 | 다국어 |
| Unity IAP | 5.4.2 | 스토어 결제 |
| LevelPlay | 9.5.1 | 광고 |
| UI Particle | 4.13.3 | UI 파티클 |
| UniTask, DOTween, Addressables | 프로젝트 사용 | 비동기, 애니메이션, UI 로딩 |
| Google Play Games, Firebase, Apps in Toss | 프로젝트 사용 | 리더보드, 분석, 플랫폼 연동 |

외부 라이브러리 원본은 이 저장소에 포함하지 않습니다. 필요한 경우 각 공급자의 배포 경로와 라이선스에 따라 별도로 준비해야 합니다.

## 자료의 기준

- 개발 기간·팀 구성·50개 스테이지 제작 결과·화면 자료: 제공된 포트폴리오 기준.
- 클래스 구조·메서드·예외 처리·빌드 분기: 공개 소스 기준.
- 소스 스냅샷 준비일: 2026-10-14.
- 포트폴리오 이후의 앱인토스 연동·저장 보호·메시 개선 코드도 현재 소스에 포함됩니다.

구현 시연 영상과 플레이 영상은 README 상단에 연결했습니다. 유튜브 업로드용 제목·설명·챕터는 [별도 문서](07-youtube.md)에 준비했습니다. 확인된 유튜브·스토어 URL이 생기면 README에 추가할 수 있습니다.

## 코드와 자료 이용

개발자 포트폴리오 검토를 위해 소스와 자료를 공개합니다. 별도의 오픈소스 이용 허락을 선언하지 않으며, 재사용·재배포가 필요하면 권리자의 허락과 관련 라이선스를 확인해주세요. 스크린샷에 포함된 아트 등 팀 제작물의 권리는 해당 권리자에게 있습니다.
