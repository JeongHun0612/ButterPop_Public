## 구현 시연 영상

파일: [ButterPop_Technical_Showcase.mp4](../media/videos/ButterPop_Technical_Showcase.mp4)

제목: **ButterPop! | Unity 2D 소프트바디 · 스테이지 제작 도구 · 서비스 구조 구현 시연**

설명:

```text
ButterPop!은 스퀴시를 떨어뜨리고 손으로 쳐 올려 스테이지 오브젝트 위에 안착시키는 모바일 2D 물리 퍼즐 게임입니다.

4인 팀에서 메인 클라이언트 개발을 담당했습니다.
Unity 6 / URP / C# / Android

00:00 프로젝트 소개
00:06 플레이 시연
00:26 Bone 관절 체인과 복원 토크
00:46 런타임 메시 변형
01:06 스테이지 제작 도구
01:18 저장한 데이터의 런타임 재구성
01:30 인터페이스 기반 서비스 구조
01:48 저장 요청 직렬화와 로드 실패 보호 검증
02:06 마무리

소프트바디는 Rigidbody2D와 HingeJoint2D로 구성한 Bone 체인에 복원 토크를 적용하고, 외형은 별도 메시 변형으로 구현했습니다.
Stage Maker의 실제 작업 데이터와 프리뷰를 캡처하고, 별도 저장 데이터로 스테이지를 재구성했습니다.
저장 검증은 실제 SaveService와 메모리 Storage를 이용한 제한된 재현입니다.

신규 촬영본과 프로젝트에 보관된 기존 녹화본을 함께 사용했습니다.
상세 구현과 코드는 공개 저장소 README에서 확인할 수 있습니다.
GitHub: https://github.com/JeongHun0612/ButterPop_Public
```

공개 소스: [JeongHun0612/ButterPop_Public](https://github.com/JeongHun0612/ButterPop_Public)

## 플레이 영상

파일: [ButterPop_Gameplay.mp4](../media/videos/ButterPop_Gameplay.mp4)

제목: **ButterPop! | 쫀득한 스퀴시와 ASMR, 모바일 물리 퍼즐 플레이**

설명:

```text
스퀴시를 떨어뜨리고, 손으로 쳐 올리고, 스테이지 위에 안착시키는 ButterPop! 플레이 영상입니다.

여러 스테이지의 실제 물리 조작과 클리어 연출을 담았습니다.

신규 촬영본과 프로젝트의 기존 녹화본을 함께 편집했습니다.

개발: 4인 팀 / 메인 클라이언트 개발 담당
Unity 6 / URP / C# / Android
```
